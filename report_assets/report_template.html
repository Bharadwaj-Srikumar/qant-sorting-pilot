The mappings work ideally.

With exact differences, all three cases sort every tested array correctly and stably. This includes duplicates and the largest requested array sizes.

Beyette and Desmulliez share the same numerical schedule. Their paired precision results are identical; this does not establish equal physical hardware performance.

Signed output resolution matters.

At matched input/output widths, an adjacent-key difference is only half an output step. Nearest-even rounding can turn it into zero.

Large arrays therefore fail frequently. Rank sorting can also produce colliding output positions. No universal algorithm winner is established.

Why can added noise improve some results? It can move a half-step difference across a rounding boundary and resolve a false tie. This is a property of the chosen quantizer model and input lattice, not evidence that physical noise generally helps sorting.

Two proposed modern mappings

@@BITONIC@@

Pair assignments depend on previous exchanges. Repeat for K active layers. Fixed-shuffle bypass steps move records without introducing another noisy difference.

@@RANK@@

Form every unordered pair from the original input. Accumulate ranks electronically, reject collisions, then place original records.

All steps currently execute in software. The photonic difference is a candidate mapping of [a,b] · [1,−1]. No Q.ANT hardware execution, native comparator, optical cascade or calibrated noise level is claimed.
